# 國小校務教學行政與鐘點代課整合系統 (Modular School Administrative Suite)

一套專為台灣公立國小教學組量身打造的**模組化、離線優先（Offline-First）、高擴充性獨立桌面網頁系統**。

---

## 🌟 核心架構與功能亮點

### 1. 離線持久化與資料庫版本控管 (Unified Data Access Layer)
- **Dexie.js / IndexedDB：** 內建 Schema Versioning 版本遷移機制，所有排代與課表資料完整保存在使用者本機電腦中，零伺服器維護負擔、保障個資安全。
- **一鍵 JSON 完整備份 / 還原：** 隨時匯出全校教師、課表、各月份請假排代紀錄與經費設定，更換電腦時一鍵無痛還原。
- **新林國小 114 學年度第 2 學期 6 月份情境範例：** 內建 30+ 位校內外教師、全校週課表與完整排代情境，開箱即用。

### 2. 課表矩陣與多格式匯入引擎 (Timetable Engine)
- **多格式適配器：** 支援拖曳 Excel (.xlsx, .xls) 或 CSV 課表檔，具備智慧欄位對齊預覽介面，相容各排課軟體（欣河、巨耀、教育局排課系統）。
- **三重視圖即時切換：**
  - 👨‍🏫 **教師個人週課表：** 顯示 1~7 節功課表、基本節數、減課節數、每週超鐘點節數統計。
  - 🏫 **班級功課表：** 支援 101~605 班級課表矩陣與任課教師對應。
  - 📊 **全校總課表：** 宏觀檢視全校課程分布與排課節數。

### 3. 常備代課人才庫與毫秒級空堂媒合 (Smart Substitute Directory)
- **智慧找人引擎：** 選取請假日期（自動換算星期）與節次，系統以毫秒級即時比對課表：
  1. **空堂校內教師：** 自動篩選該節「完全無課」之校內教師名單。
  2. **可用外聘/退休人才庫：** 依專長科目（閩南語、客語、英語、自然、體育等）與薪級俸點精準推薦，支援一鍵點選「帶入排代」。
- **批次登記功能：** 支援同一教師多節次請假一鍵拆解批次建立。

### 4. 動態經費與自選區間核算 DataGrid (Settlement Manager)
- **自選計費區間：** 支援精確日曆起訖選擇（如：`115/06/01 ~ 115/06/30` 或自訂週數）。
- **特殊扣除規則引擎：** 支援「六年級 6/12 畢業後節數扣除」與國定假日排課排除。
- **線上可編輯 DataGrid：** 可直接在儲存格輸入人事/出納提供之「勞保自付額」與「二代健保/補充保費」，系統即時重新計算 `實領金額 = 應發金額 - 扣繳總額`。

### 5. 多 Sheet 官方印領清冊 Excel 匯出引擎 (Excel Generator)
- 透過 `exceljs` 在前端純離線生成符合公家機關標準格式的 `.xlsx` 活頁簿：
  - **Sheet 1：** `114學年超鐘點總表`
  - **Sheet 2：** `代課(鐘點)`
  - **Sheet 3：** `代課(日薪)`（含日薪 1760 與導師費加給 133/日）
  - **Sheet 4：** `身心調適假`（專案補助款專用清冊）
  - **Sheet 5：** `各專案超鐘點`（額滿學校減課 / 數位精進 / 央款本土語等）
- **官方規範：** 包含公文抬頭、憑證編號（1101, 1102, 1103, 1104, 1120 等）、預算科目說明、Excel `SUM` 公式合計列，以及底部完整的 **7 級行政簽核欄**：
  `製表人 / 教學組長 | 出納組長(所得登錄) | 幹事(勞健保費) | 人事主任 | 教務主任 | 會計主任 | 校長`

## 🚀 啟動方式

### 方法一：Windows 一鍵快速啟動（推薦）
雙擊資料夾內的 `start_app.bat`，系統將自動啟動並在預設瀏覽器中開啟。

### 方法二：Python 本地伺服器啟動
在終端機中執行：
```bash
py app.py
# 或
python app.py
```
伺服器啟動後將自動開啟 `http://localhost:8080/index.html`。

### 方法三：直接開啟
直接以 Google Chrome, Microsoft Edge, Firefox, Safari 等現代瀏覽器雙擊開啟 `index.html` 即可立即離線使用！

## 📁 檔案架構

```
每月核銷/
├── index.html                   # 應用程式主頁面 (App Shell)
├── start_app.bat                # Windows 一鍵啟動腳本
├── app.py                       # 輕量 Python 伺服器
├── README.md                    # 系統使用說明
├── css/
│   └── app.css                  # 企業級現代 UI 設計系統 (高對比、自適應、打印支援)
└── js/
    ├── app.js                   # 應用程式主控制器、路由、Modal 與 Toast 管理
    ├── db.js                    # Dexie.js IndexedDB 資料庫封裝與 Schema 遷移
    ├── demo-data.js             # 新林國小 114學年度第2學期 6月份真實情境範例資料
    ├── modules/
    │   ├── dashboard.js         # 總覽儀表板模組 (KPI 指標、近期排代動態)
    │   ├── timetable.js         # 課表矩陣視圖 (全校/教師/班級) 與多格式匯入
    │   ├── substitute.js        # 智慧排代登記、空堂媒合與人才庫推薦
    │   ├── teachers.js          # 教師與外聘人才庫管理
    │   ├── settlement.js        # 經費核算 DataGrid (線上勞健保自付額微調)
    │   ├── budget-plans.js      # 經費計畫與會計科目管理
    │   └── excel-generator.js   # exceljs 多 Sheet 官方印領清冊匯出 (含 7 級簽核)
    └── vendor/
        ├── dexie.min.js         # 離線 IndexedDB 封裝函式庫
        ├── exceljs.min.js       # 離線 Excel 產生函式庫
        └── xlsx.full.min.js     # 離線課表解析函式庫
```
